# 0.4.0-dev.2 개발 스냅샷 검증 상태

이 묶음은 현재까지 구현한 자율 전문조직의 정의와 실행 코드, 디자인 자산을 고정한 개발 패키지다. 전문 보고서 전체 품질 또는 600초 달성을 인증한 릴리스가 아니다.

## 포함한 자산

오케스트레이션 8개, 전문가 페르소나 13개, 스킬 31개, 실행환경 정의 2개. 정확한 버전·내용 해시는 `release.json`의 컴포넌트 목록에서 확인한다. 각각은 provisional 상태다.

- 메타 선택, 프로젝트 계획, 실제 호스트 호출 연결과 추가 전용 실행 기록.
- 작업별 새 세션, 관련 지적·허용 판단 인계, 독립 검토 및 실제 종료 영수증.
- 원문·입력·계산·검토의 버전과 해시 연결, 변경 전파 및 재개 검사.
- DCF·사업별 가치 합산, 금융·지분청구 분석, 수정 가능한 수식 기반 Excel과 기존 HTML/PDF 디자인.
- 주식 종류별 명시적 소유자 현금흐름의 현재가치·주식 수·모회사 합계 대조. 미래 배당·재투자·계속기업 권리는 근거와 판단이 필요하다.
- 잔존가치 재투자·물리적 자본 지출 진단, 독립 산술·원문 대조 도구.
- 위험·중요성·시간·입력 사용량의 기록과 개발용 실험·승격 관리. 위험 초안은 보호된 검토를 줄이는 권한이 아니다.

## 실제 보고서 실행에서 확인한 것

LG전자 31회 실행은 모두 incomplete다. 27회는 단계별 시간 제한으로 종료됐다. 종료까지 평균 7분 23초, 중앙값 7분 59초다. 이 수치는 완성 시간도, 10분 이내 성공률도 아니다. 일부 실행에서 모델·HTML·PDF가 생성됐으나 경제적 중대 지적 또는 필수 검토 미완료로 전체 인수는 통과하지 못했다.

실행별 종료 사유·시간·원래 기록 위치·해시는 `package-status.json`에 보존한다. 원문·대화·보고서·기존 실행 기록은 원래 상태 보관함에 두며 새 보고서 입력으로 재사용하지 않는다. 이 묶음으로 확인할 것은 설치와 계산·기록 기능의 재현성이다.

## 아직 확인할 것

전체 보고서의 품질을 통과하는 최초 완성 사례, 시간 제한 외 실제 완성 시간, 같은 조건의 반복 편차, 다른 기업 적용. 주식 종류별 경제적 권리, 장기 재투자, 투자회사 청구와 초과현금 조정은 방법의 구현만으로 해결되지 않는다. FDD는 계획 능력이며 ESG의 별도 학습 어댑터는 전문 ESG 전체 업무의 승인과 구분한다.

코드 시험, ZIP·해시 대조, 이동한 설치본의 실행·활성화·복구 결과는 배포물 바깥 `evidence/`에 고정한다. 최종 배포 ZIP의 SHA-256으로 실행 코드와 해당 검증 증거를 함께 연결한다.

## 공개 배포판

공개판은 기존 회사별 동결 모델·원문과 개인 경로를 제외한다. 일반 valuation 계산·조직·검토 기준은 유지한다. 동결 역산 진단은 별도 사례 설치 없이는 capability insufficient로 종료한다. 공개된 시험 사례를 새로운 비공개 holdout 검증으로 주장하지 않는다. 이전 로컬 822개 시험 기록은 원래 스냅샷의 이력이며 공개판의 클라우드 실행 검증과 구분한다.
