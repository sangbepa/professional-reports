# Candidate five-axis scoring examples

**CANDIDATE - requires explicit user approval of this exact version before protected adoption. Uncalibrated; no source report is assigned a grade.**

The axes and passing rule are unchanged: integer 0-4 on each of evidence, economics, calculation, decision_usefulness and document_quality; each >=3 and total >=17/20. The 14 existing criteria are prompts, not separately weighted scores.

These are proposed report behaviours and counterexamples based on observed source features. Levels 0-2 are constructed failure examples, not findings that B01-B03 earned those scores. Level 4 adds proposed robustness requirements and independent verification; this review does not award any source or system an overall grade.

Each citation below resolves to the original hash in `source-anchors.json`; the machine-readable companion repeats every hash with the locator. PDF means physical one-based page; report means inner printed page.

## Application limits

- Assess material sufficiency within each unchanged axis, not the number of checklist items.
- A missing or unobservable material input is recorded as unverified and constrains the conclusion; it is never silently scored as satisfied.
- No axis waiver or redistribution. A legitimate narrow mandate must still meet all five axes for that declared purpose; a partial full-valuation attempt is not relabelled as a successful report.
- Independent review completion is recorded separately; it is necessary for the proposed level 4 but never sufficient by itself.
- The 14 existing criteria may be evidence prompts mapped to axes, not extra scored dimensions.

No count of citations, page count, brand, checklist completion, worker label or arithmetic-fixture pass can substitute for these substantive distinctions. The reviewer configuration and calibration plan remain separate, unapproved proposals.
