# Domain output names

Use these exact logical names when the current valuation plan rules require them.
Bind the matching substantive record, actual scope, unit and version at runtime.
A required output is planned until produced and checked; an alias does not pass
a gate, turn a formula specification into an executed model, or turn bridge design
into a reconciled numerical result. For a numeric bridge bind current unit/model
results and complete reconciliation before recording completion. Unavailable
implementation remains restricted.

| `financial-regulatory-capital-schedule` | `regulatory_capital_reconciliation` |
