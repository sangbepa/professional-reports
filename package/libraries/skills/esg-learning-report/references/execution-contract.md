# Learning method execution boundary

This provisional component describes a host-executed teaching method and a
standalone deterministic adapter. It is not a callable model service or a
production ESG engagement. Its method ID is `esg-learning-report-method`; the
orchestration ID is `esg-learning-report`. Both require exact registry references.

The input schema describes field/block structure. Source files, measured hashes,
cross-record references, physical-page bounds, finite numbers and changed-output
checks must be observed through the supported adapter. Schema success does not
prove any of these semantic relationships. Publication eligibility, original
meaning, framework applicability, non-company analysis scope and review
independence require actual host assessment. Do not attribute unsupported checks
to the CLI merely because they appear in the method contract.

The host preserves original snapshots, authored request versions, actual adapter
commands/results, inspected artifact hashes, limitations and failed attempts.
Review records must identify actual independent channels and inspected scope for
source, judgment and document review. A source reviewer examines citation
entailment and reported methods; a judgment reviewer challenges conclusions and
missing evidence; a document reviewer inspects every current rendered page.
Mechanical adapter checks and author self-checks stay separately labeled.

Changed source bytes, input values, claims, qualifications or output hashes stale
the affected downstream review. Preserve findings and re-review exact revisions;
do not invent closure. If no independent reviewers are available, a teaching
artifact may be emitted with explicit pending review, but no reviewed or assured
completion can be claimed. The standalone interface has no `Run.finish` authority.

Use only public-source teaching reconstruction. Do not declare GRI compliance,
assurance, issuer authorization or operational control effectiveness. No
production promotion, native reviewer invocation or protected valuation
acceptance is implemented by this method. Missing dependencies, originals,
rendering or review channels remain unresolved until actual checks establish them.
