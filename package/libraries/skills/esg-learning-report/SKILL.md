---
name: esg-learning-report-method
description: Reconstruct public ESG disclosures as an unofficial learning report with traceable claims, measurement boundaries and separately recorded independent review coverage.
---

Read `contract.json`, `references/execution-contract.md` and the pinned
`esg-learning-report` orchestration policy. Frame the actual company, period,
cutoff, original-source access, measurement boundaries and learning basis before
drafting. Keep entity/site/value-chain and missing-evidence qualifications clear.

Use `schemas/esg-learning-report.schema.json` from the pinned package root for
the `esg-learning-report/1` request. Bind sources to actual files and hashes and
physical PDF pages. Preserve reported meaning, method, perimeter and units.
Every material company assertion needs a claim binding; every numeric metric
observation needs a source/page. `null` is unavailable. Methodological commentary classified
`analysis` requires `non_company_assertion: true`, no claim IDs, and must
explicitly avoid assertions about the company. Unavailable null observations may
omit both citation fields; numeric observations always require both.

Invoke the installed standalone `pr.esg` prepare/build/check interface. Keep its
actual mechanical outcomes separate from original-source fidelity and judgment.
Do not invent an emission factor, intensity denominator, framework-compliance
statement, review receipt or assurance conclusion. Keep `비공식 학습용` visible.

Return the prepared input, learning report, review register and limitations with
actual input/output bindings. The host arranges independent source, judgment and
document reviews and writes their actual coverage and dispositions. If unavailable,
mark them pending/unavailable and restrict the conclusion. Inspect every rendered
page for actual document review; CLI checks alone do not establish this coverage.

This method does not spawn agents, change protected criteria, activate a release
or complete the generic ESG production domain. Follow installed adapter help for
optional tools; missing tools and unresolved findings remain recorded limitations.
